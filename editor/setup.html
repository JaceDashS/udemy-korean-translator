사전 도우미 등록 (PC마다 처음 한 번)

Chrome은 보안상 확장 프로그램이 PC에서 프로그램을 실행하지 못하게 막습니다. 아래 명령으로 "이 확장은 사전 도우미를 실행해도 된다"고 한 번만 등록하면, 그다음부터는 사전 편집기의 버튼으로 모두 진행됩니다.

순서

  1. 명령 복사를 누릅니다.
  2. Windows 키를 누르고 PowerShell을 입력한 뒤 Enter로 엽니다.
  3. PowerShell 창에서 마우스 오른쪽 버튼(또는 Ctrl+V)으로 붙여넣고 Enter를 누릅니다.
  4. 창에 Done.이 나오면 끝입니다. 이 탭과 사이드 패널이 알아서 다음 단계로 넘어갑니다.

이 명령이 하는 일

  • 도우미 스크립트(dictionary-host.ps1)를 %USERPROFILE%\.udemy-dictionary-helper에 내려받습니다.
  • Chrome이 도우미를 찾을 수 있도록 현재 사용자 레지스트리에 키 하나를 씁니다. 관리자 권한은 필요 없습니다.
  • 아무것도 설치하지 않습니다. GitHub CLI 설치와 로그인은 사전 편집기에서 버튼을 눌러 승인할 때만 진행됩니다.

내용을 먼저 확인하려면 register.ps1을 열어 보세요.
