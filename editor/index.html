Dictionary Editor

단어 한 행 = 단어 1개. 뜻은 비워둘 수 있습니다(비우면 영어 그대로).

도우미가 연결되지 않았습니다. 등록하려면 PC에서 한 번 설정하세요.

  1. Node.js 18 이상, git, GitHub CLI(gh)를 설치합니다.
  2. 터미널에서 gh auth login을 실행합니다. Git 인증도 함께 설정하세요.
  3. 저장소를 받아 node tools/dictionary-helper.js를 실행합니다. 그 창은 편집하는 동안 열어 두세요.
  4. 이 페이지를 새로고침합니다.

도우미 없이 내용을 복사해 직접 올릴 수도 있습니다.
