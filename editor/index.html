Dictionary Editor

단어 한 행 = 단어 1개. 뜻은 비워둘 수 있습니다(비우면 영어 그대로).
단어 뜻 대소문자 구분
  1. GitHub 탭에서 Fork를 누릅니다(처음 한 번). "Copy the main branch only"는 끄세요. dictionary 브랜치가 필요합니다.
  2. 포크한 저장소에서 dictionary 브랜치의 dictionary.json을 열고 연필 아이콘(Edit)을 누릅니다.
  3. 내용을 모두 지우고 붙여넣습니다(복사된 내용). 아래 상자에서도 복사할 수 있습니다.
  4. 커밋 옵션에서 Create a new branch for this commit and start a pull request를 선택하고 Propose changes를 누릅니다. 이 PR이 소유자에게 전달됩니다.

엑셀에서 행을 복사해 단어 칸에 붙여넣으면 여러 행이 한 번에 추가됩니다. 열 순서는 단어 · 뜻 · 대소문자구분(Y)입니다. Enter는 아래 칸으로 이동합니다.
